# `admin.broadcast` 🔴

[← action 一覧](./README.md)

> 種別: **管理** ／ 実装: `adminBroadcast_()`

LINE 公式アカウントの**友だち全員**にメッセージを送ります。

## 認証

管理トークン。

## payload

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `text` | string | ✅ | 本文（プレーンテキスト） |

## 戻り値

```json
{ "sent": true }
```

## エラー

| code | 条件 |
| --- | --- |
| `AUTH` / `FORBIDDEN` | 認証・権限 |
| `CONFIG` | `LINE_MESSAGING_TOKEN` が未設定 |
| `BROADCAST` | Messaging API がエラーを返した（本文を `error` に含む） |

## ⚠ テストで実行しないこと

> **実際に全員へ届きます。取り消せません。**
>
> さらに、**無料枠（月200通）を友だちの人数分消費します**。
> 友だちが100人いれば、1回の配信で100通です。予約確定通知（1予約1通）の枠を
> 圧迫するのは主にこの action です。

## 挙動の注意

- 送信前の確認や宛先の絞り込みはありません。`text` をそのまま全員に送ります
- 空文字でも送信されます（`String(p.text || "")`）
- 送信結果の記録（誰に届いたか）は残りません
