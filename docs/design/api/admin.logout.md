# `admin.logout` 🟡

[← action 一覧](./README.md)

> 種別: **管理** ／ 実装: `adminLogout_()`

管理セッションを破棄します。

## 認証

管理トークン（実際には検証しません。下記参照）。

## payload

なし。

## 戻り値

```json
{ "ok": true }
```

## エラー

なし。**常に成功します。**

## 挙動の注意

- トークンが 64桁hex の形式であれば `CacheService` から削除します。
  それ以外の値（LINE の JWT など）は**何もせず成功を返します**
- 認証チェックをしていないため、**他人のトークンを渡せばそれを破棄できます**。
  トークンを知っている時点で本人なので実害はありませんが、設計上の注意点として記載します
- クライアント側は先に localStorage を消すため、この呼び出しが失敗しても
  ログアウト自体は成立します
