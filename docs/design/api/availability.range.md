# `availability.range` 🟢

[← action 一覧](./README.md)

> 種別: **公開** ／ 実装: `availabilityRange_()`

指定期間の30分枠と、その空き状況を返します。
**「予約できるかどうか」の唯一のソース**です。クライアントは自前で時刻判定をしません。

## 認証

不要。

## payload

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `court_id` | string | ✅ | `courts.list` の `id` |
| `from` | ISO8601 | ✅ | 開始日（日付部分のみ使用） |
| `to` | ISO8601 | ✅ | 終了日。**この日は含まない** |

```json
{ "court_id": "court-half", "from": "2026-08-01T00:00:00+09:00", "to": "2026-08-02T00:00:00+09:00" }
```

## 戻り値

```json
{
  "slots": [
    {
      "slot_id": "court-half-2026-08-01T09:00:00+09:00",
      "starts_at": "2026-08-01T09:00:00+09:00",
      "ends_at": "2026-08-01T09:30:00+09:00",
      "is_available": true
    }
  ]
}
```

1日あたり **22枠**（9:00〜20:00 の30分刻み）を機械生成して返します。

## `is_available` が `false` になる条件

次のいずれかに当てはまると `false` です。

| # | 条件 | 補足 |
| --- | --- | --- |
| 1 | **貸切（CHARTER）の CONFIRMED 予約**が重なる | |
| 2 | `Slots` の **`OPEN` 以外の行**が重なる | `CLOSED` / `BLOCKED` |
| 3 | **開始時刻が現在時刻より過去** | 2026-08 追加 |

> ⚠ **フリー（FREE）の予約は `is_available` を `false` にしません。**
> フリーは同一時間帯に合計9名まで入れるため、枠としては空いているからです。
> 人数の残りは `admin.slots.list` の `free_remaining` で確認できます。

## エラー

| code | 条件 |
| --- | --- |
| `CONFIG` | `Reservations` / `Slots` シートが無い |

## 挙動の注意

- **`to` は排他**です。1日分を取るなら翌日の `00:00` を指定します
- 期間が長すぎる場合、内部のガードで **400日**で打ち切ります
- 「予約済み」と「休業」の区別はできません。管理画面用には
  [`admin.slots.list`](./admin.slots.list.md) を使ってください

## 呼び出し元

- LIFF カレンダー画面 — 月単位で取得し、日ごとの空き比率から ◎ / ○ / × を出す
- LIFF 時刻表画面 — 1日分を取得し、枠ごとの選択可否に使う
