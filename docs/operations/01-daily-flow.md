# 1日の流れ

[← 運用ガイド](./README.md)

営業日に運営が行う定型作業です。**太字**が最低限やること。

---

## 開店前（9:00 まで）

| # | 操作 | 画面 | 動く action |
| --- | --- | --- | --- |
| 1 | **管理画面にログインする** | 🖥 `/admin` | `admin.login` → `admin.session` |
| 2 | **本日の予約を確認する** | 🖥 予約一覧（確定タブ） | `admin.reservations.list` |
| 3 | 週の埋まり具合を見る | 🖥 カレンダー | `admin.slots.list` |
| 4 | 臨時休業があれば設定する | 🖥 カレンダー | `admin.slots.set` |

### ログインの二層

```
[1] Basic 認証（ブラウザのダイアログ）  → /admin に入る
        ↓
[2] 管理ログイン（画面内のフォーム）    → データ操作の認可
```

**ID は同じでもパスワードは別**です。混同しやすいので注意してください。
セッションは6時間有効で、操作のたびに延長されます。

## 営業中

| 場面 | 操作 | シナリオ |
| --- | --- | --- |
| お客様が来場した | **受付（チェックイン）** | [S-07](./03-scenarios-visit.md#s-07) / [S-08](./03-scenarios-visit.md#s-08) |
| 料金を受け取った | **入金を記録** | [S-09](./03-scenarios-visit.md#s-09) |
| 予約なしの来店 | カウンター受付 | [S-11](./03-scenarios-visit.md#s-11) |
| 電話で予約を受けた | カウンター受付 | [S-06](./02-scenarios-booking.md#s-06) |
| 電話でキャンセル依頼 | 管理者キャンセル | [S-13](./04-scenarios-change.md#s-13) |
| 予約時間を過ぎても来ない | No-Show を記録 | [S-14](./04-scenarios-change.md#s-14) |
| **お金を返した** | **返金を記録** | [S-24](./04-scenarios-change.md#s-24) |

### 受付の順番（推奨）

```
1. お客様に予約番号を言ってもらう（または QR を見せてもらう）
2. 一覧で検索して、団体名・時間・金額を画面で確認
3. 「受付する」を押す          ← 取り消せない
4. 料金を受け取る
5. 「入金を記録」を押す
```

> ⚠ **3 と 5 は別の操作**です。受付だけでは売上に計上されません。

### 返金したときの順番

```
1. お客様に現金を返す
2. 「返金を記録」を押す        ← ここまでで1セット
```

> ⚠ **キャンセルは返金ではありません。** キャンセルしただけでは売上に残ったままです。
> **お金を返したら必ず「返金を記録」まで**行ってください（[S-24](./04-scenarios-change.md#s-24)）。

## 閉店後（20:00 以降）

| # | 操作 | 画面 | 動く action |
| --- | --- | --- | --- |
| 1 | **本日の入金漏れを確認する** | 🖥 予約一覧（完了タブ） | `admin.reservations.list` |
| 2 | 来なかったお客様を No-Show にする | 🖥 予約一覧 | `admin.reservations.markNoShow` |
| 3 | **返金の記録漏れを確認する** | 🖥 予約一覧・ダッシュボード | `admin.reservations.list` / `admin.sales.summary` |
| 4 | 売上を確認する | 🖥 ダッシュボード | `admin.sales.summary` |
| 5 | ログアウトする | 🖥 | `admin.logout` |

### 入金漏れの見つけ方

予約一覧を「完了」で絞り、**入金が「未入金」のまま**の予約を探します。
受付はしたが入金記録を忘れた、という取りこぼしがここに出ます。

### 返金の記録漏れの見つけ方

**その日に現金を返した予約が「入金済み」のままになっていないか**を見ます。
返金は現場の判断で起きるので、記録を忘れると売上だけが多いまま残ります。

ダッシュボードの「返金」の件数と、その日に実際に返した件数が合っているかで確認できます。
